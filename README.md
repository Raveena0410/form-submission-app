# 📝 Form Submission App

This is a simple full-stack form submission app using HTML, JavaScript, Express, and MongoDB.

## Features

* Submit form data
* Backend API using Express
* Data stored in MongoDB

## How to run

1. Install dependencies: `npm install`
2. Start server: `node server.js`
3. Open `form.html` in browser

## Note

MongoDB must be running locally for this project to work.
